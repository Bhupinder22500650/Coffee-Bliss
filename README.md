# Coffee Bliss ☕ (Expo + React Native)

A cross-platform mobile application built with **React Native** and **Expo**.  
Coffee Bliss allows users to browse a coffee menu, customize drinks, add them to a cart, and place mock orders with a clean and user-friendly interface.

---

## ✨ Features (Final Project)
- **Login Screen** – basic mock authentication, session saved with AsyncStorage  
- **Coffee Menu** – loaded from local JSON  
- **Customisation** – choose drink size, milk type, sugar level  
- **Cart Management** – add/remove items, view order summary  
- **Checkout Flow** – place mock order → success screen 
- **Haptic Feedback** – subtle vibrations on key actions (expo-haptics)  
- **Consistent UI Theme** – coffee-themed design across all screens  

---

## 🚀 Run Locally
```bash
# 1) Install Node.js (LTS recommended)
# 2) Clone this repo and navigate into project
cd CoffeeBliss
# 3) Install dependencies
npm install
# 4) Start Expo
npx expo start
# 5) Scan QR with Expo Go (iOS/Android)
```
